# Get Started

This guide has moved to the CyteType documentation, which covers the R and Python clients together:

- [Quickstart (R)](https://docs.nygen.io/CyteType/getting-started/quickstart-r/): preprocess a dataset with Seurat, run CyteTypeR and explore the results.
- [Installation](https://docs.nygen.io/CyteType/getting-started/installation/) and [Sign in and API keys](https://docs.nygen.io/CyteType/getting-started/sign-in/).
- [Prepare your data](https://docs.nygen.io/CyteType/guides/prepare-data/): what `PrepareCyteTypeR()` needs from the Seurat object and the marker table.
- [Results in AnnData and Seurat](https://docs.nygen.io/CyteType/results/results-in-your-data/): the columns and tables that `CyteTypeR()` adds to the object.
- [R function reference](https://docs.nygen.io/CyteType/reference/r-api/).

In R, `?PrepareCyteTypeR`, `?CyteTypeR` and `?GetResults` open the help pages of the installed version.
